# family-menu

家庭每日食谱系统:一次生成一周菜单,自动排菜、算份量、按采购批次拆购物清单,并为幼儿标注每道菜的分菜时机。

**打开即用:** https://thinkryh.github.io/family-menu-pro/

## 它解决什么

- **排菜**:77 道菜谱按时令、冷却期、主料重复度自动排一周三餐,面食只上晚餐且每周不超 3 次
- **一菜两做**:同一道菜在「加盐加辣之前」盛出幼儿份,不做两桌菜;做不到的菜直接标明不适合并写清原因
- **买菜**:按周一/周三/周六三批拆清单,耐储食材并入首批,附储存方式与先吃顺序,可勾选、可复制给另一位掌勺
- **每周核对**:鱼、猪肝、面食、汤的次数对照目标实时显示,缺口标暖色

## 结构

```
data/         菜谱、食材、家庭画像、幼儿喂养规则(纯 JSON,改这里)
app/          template.html — 页面模板,唯一手改入口
docs/         index.html — 构建产物,GitHub Pages 发布目录,禁止手改
scripts/      build.js — 校验 + 数据内嵌 + 构建
```

## 开发

```bash
node scripts/build.js --validate   # 只校验数据
node scripts/build.js              # 校验 + 构建 docs/index.html
```

页面是单文件、零依赖、零后端:排菜算法在浏览器端运行,数据在构建时内嵌,菜单和勾选状态存 localStorage。

详见 `CLAUDE.md`(项目规格)与 `SOP.md`(开工流程)。

## 免责

菜谱中的幼儿喂养建议按 `data/baby_rules.json` 生成,仅供参考,不构成医学或营养学建议。请结合自家孩子的实际情况和儿保医生意见判断。
